# node_exporter

Роль Ansible, которая устанавливает и конфигурирует node-exporter из системного пакета.

## Описание

node-exporter разворачивается на всех хостах в инвентаре для сбора базовых метрик с хостов. Роль:

- устанавливает пакет `prometheus-node_exporter` из настроенных репозиториев ОС (`state: present`: версия не фиксируется, установленный пакет не обновляется);
- снимает маскирование с юнитов `node_exporter.socket` и `node_exporter.service`, включает их автозапуск и запускает их;
- задаёт аргументы node-exporter в переменной `OPTIONS` файла `/etc/sysconfig/node_exporter`;
- добавляет drop-in `/etc/systemd/system/node_exporter.service.d/restart.conf` с `Restart=on-failure`, не изменяя юниты из пакета;
- проверяет, что метрики отдаются по `http://127.0.0.1:9100/metrics`.

Порт 9100 задаётся юнитом `node_exporter.socket` из пакета (socket activation, `--web.systemd-socket`), поэтому `--web.listen-address` не используется. Сервис работает от непривилегированного пользователя `node_exporter`.

Каталог textfile-коллектора пакета: `/var/lib/node_exporter/textfile_collector`.

Сервис перезапускается только при изменении конфигурации или drop-in. При изменении drop-in перед перезапуском выполняется `systemctl daemon-reload`.

## Режим проверки (`--check`)

- Проверка `/metrics` пропускается.
- Если установка пакета только имитируется (пакет ещё не установлен), перезапуск сервиса, включение автозапуска и запуск юнитов пропускаются: юнитов на хосте ещё нет.
- Изменения пакета, `/etc/sysconfig/node_exporter` и drop-in по-прежнему отображаются как ожидаемые (`changed`), там где это применимо.

## Поддерживаемые ОС

- РЕД ОС 7.3
- РЕД ОС 8

## Требования

- В репозиториях ОС доступен пакет `prometheus-node_exporter`.
- Порт 9100 свободен: если node-exporter ранее запускался другим способом (например, в контейнере Docker), остановите и удалите его до первого запуска роли.

## Переменные

| Переменная | Значение по умолчанию | Описание |
|---|---|---|
| `node_exporter_ntp_server` | `127.0.0.1` | NTP-сервер, который опрашивает коллектор `ntp` (`--collector.ntp.server`). |

Значение по умолчанию `127.0.0.1` работает, только если на самом хосте запущен NTP-сервер, принимающий запросы через localhost (например, chronyd с соответствующей директивой `allow`). Иначе коллектор `ntp` завершается с ошибкой (`node_scrape_collector_success{collector="ntp"} 0`), а остальные метрики продолжают отдаваться. Укажите доступный NTP-сервер своей инфраструктуры в переменных инвентаря.

Остальной набор коллекторов и их параметры задаются в шаблоне `templates/etc_sysconfig_node_exporter.j2`.

В значениях аргументов нельзя использовать обратную косую черту, кавычки и пробелы: systemd удаляет обратную косую черту и кавычки при подстановке `$OPTIONS` в `ExecStart`. Например, вместо `\.` в регулярных выражениях используется `[.]`.
